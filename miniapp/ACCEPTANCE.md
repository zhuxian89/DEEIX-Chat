## 真机验收矩阵

- [ ] 新微信用户无表单完成一键登录，后端仅新增一个标准用户和一条绑定。
- [ ] 杀死进程后重开仍是同一用户，旧小程序会话有界，Web 会话不受影响。
- [ ] 首页订阅/余额与 Web/后台同一用户事实一致。
- [ ] “AI 对话”一次点击创建固定模型会话，完成中文、Emoji 和至少三轮连续对话。
- [ ] 对话中选择、上传并发送一张图片；上传域名和模型处理正常。
- [ ] 流式回答过程中停止，不残留“生成中”状态，也不显示误导性的网络错误。
- [ ] “AI 生图”独立创建固定模型会话，生成一张图片并预览、保存到相册。
- [ ] request、uploadFile、downloadFile 合法域名均在关闭“不校验合法域名”后通过。
- [ ] access token 临近过期后 refresh 轮换成功；杀进程后内存令牌消失并重新静默登录。
- [ ] Wi-Fi/蜂窝网络切换后失败提示明确，重新操作可以恢复。
- [ ] 一次收费对话和一次生图分别只产生既有语义的一次扣费。
- [ ] 默认对话或生图模型缺失/无权限时仅禁用对应快捷入口，不静默换模，也不阻塞另一项能力。
