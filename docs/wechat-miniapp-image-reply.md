# 公众号回复「小程序」发送小程序码

用户向公众号发送「小程序」时，后端通过微信被动回复返回一张图片，用户可以识别正式版小程序码进入。关键词去除首尾空白后精确匹配，「打开小程序」等其他文字不自动匹配。

## 配置与上线

1. 从小程序后台下载正式版小程序码，确认它指向当前正式发布的小程序。
2. 将图片上传为**同一公众号的永久图片素材**，保存接口返回的 `media_id`。临时素材有有效期，不适合作为长期入口；图片 URL 也不能代替素材 ID。
3. 部署支持图片回复的后端与管理前端。
4. 在网站后台「微信公众号管理 → 模板」中新建模板：名称「小程序码」、回复类型「图片」、内容填写素材 `media_id`。
5. 在「关键词」中新建规则：关键词「小程序」、功能「回复图片」、绑定「小程序码」模板，并保持规则和模板启用。
6. 在微信中发送「小程序」，确认收到的是图片、能够识别进入正式版小程序；再发送 `13004`，确认注册码回复仍正常。

验证通过后，可以在 `13004` 现有回复末尾补充：

```text
回复【小程序】获取小程序码。
```

也可以先在微信手机端验证以下消息菜单链接，点击后应向公众号发送「小程序」关键词，再由图片规则回复小程序码：

```html
<a href="weixin://bizmsgmenu?msgmenucontent=%E5%B0%8F%E7%A8%8B%E5%BA%8F&msgmenuid=1">点击获取小程序码</a>
也可回复【小程序】获取。
```

这是待真机验证的文案选项；必须确认当前公众号的被动回复能显示链接、点击能触发关键词，再用于线上文案。保留手动发送关键词的备用说明。

这一功能仅提供小程序入口；注册码开通聊天是另一项功能，上线前不在回复中承诺可以使用注册码开通。

## 实现与维护

- 复用已有关键词、回复模板和调用日志表，不变更表结构。新增动作 `reply_image` 和模板类型 `image`，图片模板的 `content` 保存素材 ID。
- 微信回调在通过现有签名校验后返回 `MsgType=image` 和 `Image/MediaId`；回调期间不调用微信素材接口，避免上传或下载导致回复超时。
- 图片回复记录 `handled` 日志，不发放注册码，也不产生注册码发放记录。Telegram 镜像显示 `[图片] 模板名称`。
- 注册码规则只允许绑定文字模板，图片规则只允许绑定图片模板。已有模板不能直接变更类型，需要新建模板后重新绑定，避免影响共用该模板的其他关键词。
- 更换小程序码时，先上传新的永久图片素材，再编辑图片模板的素材 ID。下一次关键词请求即读取新配置。
- 停用「小程序」关键词即可停止图片回复；恢复启用即可继续使用。不要删除仍被引用的公众号永久素材。

本地测试使用模拟素材 ID 和模拟微信回调，不会向真实用户发送消息。实际图片显示与小程序码识别需要上线后通过微信验收。
