# Web 生图入口

侧栏“生图”打开一个新的空会话，沿用现有输入框、生成接口和历史记录。发送消息前不会创建持久化会话或调用收费生成接口。

## 配置

在“后台 → 会话配置 → 默认生图模型”选择平台模型并保存。下拉框只列出已启用、有可用来源且声明 `image_gen` 能力的模型。

配置保存在 `system_settings`：`namespace=chat`、`key=conversation_default_image_model`，字符串值为平台模型名称。默认值为空，不覆盖已有配置，不修改表结构。

- 留空：使用当前用户可用模型列表中的第一个生图模型。
- 指定模型：同时检查用户可用目录和生图能力；不可用时提示错误，不自动换模。
- 配置读取失败：提示错误，不回退到聊天模型。
- 保存后的配置用于下一次“生图”，不修改已有会话的模型。

“新对话”的 `chat.conversation_default_model` 和个人默认模型配置保持独立。生图入口不会写入个人默认模型或个人模型参数。小程序的默认生图模型配置不受影响。

读取候选使用已认证接口 `GET /api/v1/conversations/default-image-model-candidate`；实际生成继续使用现有模型权限和计费链路。要恢复自动选择，可在后台清空这一配置值。
