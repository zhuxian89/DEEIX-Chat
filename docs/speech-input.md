# 小程序语音输入

小禾、AI 对话和 AI 生图共用语音输入组件。点击麦克风切换为“按住说话”，按住录音，松手后转文字。左上滑并松手取消，右上滑并松手转文字；滑回原处可继续说。普通松手同样先预览，不会自动发送。

识别后打开独立的文字确认界面，可编辑，再点“发送”。识别结果不会回填原输入框：原有草稿与识别文字只在预览中合并，取消后原草稿保留。确认发送会直接调用原有发送入口，已有图片附件、聊天、记忆、图片生成与计费继续使用原有流程。

录音、识别和预览期间暂停小禾主动聊天。切到后台、离开会话或取消会丢弃迟到的识别结果；授权未完成时松手不会在随后授权成功时偷偷开始录音。录音达到 59 秒自动结束并转文字，但此时手指位于取消区域则直接丢弃。重复点击发送只提交一次，模型或图片条件不满足时保留预览文字。

## 参数配置

复用管理后台 **参数配置** 页面的 `speech` 分组。部署新版后端后，填写两项凭据，再开启语音输入，保存后立即生效：

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `tencent_secret_id` | 空 | 腾讯云语音识别 SecretId |
| `tencent_secret_key` | 空 | 腾讯云语音识别 SecretKey |
| `engine` | `16k_zh` | 普通话；可选 `16k_zh-PY` 中英粤、`16k_zh_dialect` 多方言 |
| `enabled` | `false` | 首次启动提供完整凭据时自动开启，也可在后台控制 |

两项凭据均通过现有 `DATA_ENCRYPTION_KEY` 加密存入 settings，管理接口只返回是否已配置，修改时留空保留已有值；审计日志沿用既有脱敏规则。读取使用 `RuntimeValuesByNamespace`，下一次请求直接使用最新参数。不使用已有 OCR 的腾讯云密钥，不修改表结构。

也支持可选的启动导入，沿用微信配置的 `Config → settings.Seed → 加密 → 仅插入缺失 key` 流程。部署端通过私密环境变量 `SPEECH_TENCENT_SECRET_ID`、`SPEECH_TENCENT_SECRET_KEY` 提供初始值；完整凭据会令首次插入的 `speech:enabled` 为 `true`。直接在后台填写时不需要设置这两个环境变量。运行时始终读取参数表，后台更新密钥、关闭功能或修改引擎后，重启和再次部署都不会覆盖。初始化完成后可以移除这两个环境变量。真实凭据不得写入 Git、镜像或小程序包。

若此前已经创建过空的 `speech` 配置，启动种子会保留这些已有值，需要部署时通过现有参数配置更新，不能靠重启覆盖。缺少任一初始凭据时默认保持关闭。

## 接入与行为

- `GET /api/v1/speech/capabilities`：鉴权后返回开关与最大录音时长，关闭或配置失效时不显示麦克风入口。
- `POST /api/v1/speech/transcriptions`：鉴权后提交 `{ "audio": "Base64 MP3" }`，返回 `{ "text": "识别文字", "durationMs": 1000 }`，继续使用统一响应信封。
- 录音使用微信 RecorderManager：16 kHz、单声道、48 kbps MP3，59 秒自动结束，给腾讯云 60 秒上限留余量。原始文件限制 512 KiB，HTTP 请求体限制 750 KiB。
- 音频仅在当前录音临时文件和请求内存中处理。结束、失败及取消后清理临时文件；服务端不保存音频，不创建文件/会话/记忆记录，不记录识别文本及腾讯云原始错误。腾讯云收到音频进行识别。
- 每用户每分钟 10 次、全局每秒 20 次（复用现有限流存储），单实例最多 4 个识别请求、单用户同实例最多 1 个；20 秒超时。语音识别成本由平台承担，正常发送后的模型调用按现有规则计费。
- 取消、切后台、切换会话或页面后，迟到结果不会修改草稿。已经送到服务端的识别可能仍会完成，但不会自动发送消息。小禾在录音和识别期间不会主动接话。
- Web 使用浏览器 SpeechRecognition；微信使用录音加腾讯云识别适配。保留 Web 的追加草稿、用户确认发送语义，第一版不展示实时逐字转写。

## 部署与验收

部署新版后端后，在参数配置中填写凭据并开启语音输入，再使用配套小程序版本。微信公众平台的《用户隐私保护指引》需要包含麦克风/录音用途及腾讯云处理录音的说明；客户端通过隐私授权与 `scope.record` 授权后才录音。

验收覆盖：启动自动导入并开启、凭据加密及脱敏、重启保留后台修改、留空不清密钥、配置更新立即生效、缺失配置不能开启、未登录拒绝、音频大小限制、固定腾讯云目的地址、重复请求/取消和草稿保留。微信真机另验证首次授权、拒绝后重新授权、录音打断、切后台、中文识别及三个入口的可用性。

接口与限制以 [腾讯云一句话识别文档](https://cloud.tencent.com/document/api/1093/35646) 为依据；录音适配参考 [Taro RecorderManager](https://docs.taro.zone/docs/apis/media/recorder/RecorderManager)。
